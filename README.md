# Демо-сайт автосервиса «Просвет»

Одностраничный сайт (лендинг) автосервиса в двух вариантах оформления.
Собрано по системе «вайб-скиллов»: структура, тексты и анимации по шаблону ниши,
картинки сгенерированы через kie.ai (seedream/5-pro), проверка покадрово на 1440×900 и 390×844.

## Варианты

| Версия | Палитра | Живое демо | Код |
|---|---|---|---|
| v1 | «Графит + красный» | https://lni3fxssf4ov4.kimi.page | корень репозитория |
| v2 | «Антрацит + лёд» + спецэффекты (градиенты, свечение) | https://fba6v2xkvpfwu.kimi.page | папка `v2/` |

## Структура

- `index.html`, `vibe.css`, `vibe.js`, `assets/` - вариант v1 (корень)
- `v2/` - вариант v2 (та же структура файлов)
- Слоты `{{город}}`, `{{цена}}`, `{{телефон}}` и др. не заполнены - подставляются данные заказчика
